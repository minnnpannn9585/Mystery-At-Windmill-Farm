## 2. Player movement & interaction

```mermaid
flowchart TD
    A[Douyin SDK native walk] --> B{Interaction type}
    B --> C[Walk into DouyinInteractor zone]
    C --> D[SDK shows screen interaction button]
    D --> E[Click → DialogueTrigger.StartDialogue / ClueTrigger.SetClue / custom handler]
    B --> F[Walk into trigger collider]
    F --> G[OnPlayerTriggerEnter if isLocal]
    G --> H[CheesePickup / ClimbPathPoint / DialogueAreaTrigger]
    B --> I[DialogueAreaTrigger zone]
    I --> J[Auto StartNpcDialogue without button]
```

**Movement**: Douyin platform handles avatar locomotion. `MainController.Update` **disables the SDK fly button** every frame (`HandType.Right, UIType.Fly`). No walk logic in Lua; `MainCharacter.cs` is an empty stub.

**Interaction patterns**:
1. **Click-to-interact** (primary): NPCs and most E-points have `DouyinInteractor` + `DialogueTrigger` or `ClueTrigger`. Player walks into `InteractionArea` → SDK button appears → click fires Lua.
2. **Trigger-enter** (passive): `CheesePickup`, `ClimbPathPoint`, `DialogueAreaTrigger` use `OnPlayerTriggerEnter(douyinPlayer)` with **`actor.isLocal`** check (multiplayer-safe).
3. **Forced dialogue**: `DialogueAreaTrigger` — enter box collider, no button (tree 1-A, mouse E39, crow roof, etc.).
4. **Dynamic enable/disable**: Controllers toggle `InteractionArea.enabled` + colliders; closing always calls **`DisableInteraction()`** to clear stuck SDK buttons. Convention: **never call `EnableInteraction` when opening** (except `CrowInteractionController`).

**Teleport**: `LevelTeleport` / debug / ending use `DouyinActorService.GetLocalActor()` → `actor:Teleport()` or direct `position`/`rotation`.

## 6. Dialogue system flow

```mermaid
sequenceDiagram
    participant Player
    participant Trigger as DialogueTrigger / AreaTrigger
    participant Loader as LoadNPCScript
    participant Mgr as NpcDialogueManager
    participant Vars as SetGlobalVar

    Player->>Trigger: click or enter zone
    Trigger->>Loader: StartNpcDialogue(npcName, startId)
    Loader->>Loader: NPCData currentBranchId → lua module
    Loader->>Loader: DialogueData/{module}.DouyinScript.DialogueConfig
    Loader->>Mgr: StartDialogueWithData(config, startId)
    Mgr->>Mgr: UpdateDialogueUI (skip empty dispatchers / RotatePool)
    Mgr->>Vars: ApplySetVariables
    Mgr->>Mgr: CheckAndUnlockBranch (mutate currentBranchId)
    alt Normal node
        Mgr->>Mgr: typing → Next click
        Mgr->>Mgr: GetNextNodeByConditionDetailed or Next
    else Question node
        Mgr->>Mgr: filter Options by DisplayConditions
        Mgr->>Mgr: OnOptionSelected → PerformOptionJump
        Note over Mgr: ShopAction → MouseShop_HandleAction
    end
    Mgr->>Mgr: EndDialogue → ChainDialogue? → next NPC
```

**Key node fields** (in DialogueConfig Lua tables): `Type`, `NpcName`, `Dialogue`, `Next`, `ConditionBranches`, `SetVariables`, `UnlockBranches`, `Options[]` with `DisplayConditions`, `ShopAction`, `BranchFlag`, `ChainDialogue`, `RotatePool`, `DocTag`.

**Branch unlock**: `CheckAndUnlockBranch` writes `npc.currentBranchId` in memory `_NPCDataConfig`; next click loads new lua file from `storyGraphs[].luaAssetPath`.

**Mouse shop integration**: Question options with `ShopAction` (`cheap`, `premium`, `pay8_mint`, `pay8_frog`) delegate to `MouseShop_HandleAction` before normal jump.

1. Player opens attic window (`ComicGateTrigger` / `ComicGate_OnInteract`)
2. Sets `Comic_Revealed = true`

4. Comic panels: click to advance, crossfade, `audio_endingLoop`
5. Final panel fade → **black hold** → `ApplyTeleportAndFlags`:
   - `DouyinTaskService.SendEvent(Terminal)` (skipped in simulator)

   - `_G["ResetPosition"]()` (spawn teleport)
   - `DouyinUIService.SetNativeUIVisible(true)`
