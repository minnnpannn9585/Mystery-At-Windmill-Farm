# 水下视觉效果方案 v1（吉卜力口径 · 待审核）

> 目标：**玩家潜到水下抬头时，第一眼就能读出「我在水下面」**，且不破坏现有 L1 视觉定调。
> 依据：`Ghibli_风格指南_龙猫口径.md`（暖光 / 冷影 / 厚云 / 有风）、现有 URP+FlatKit 渲染链路、`WaterSurface` 世界查询。
> 状态：设计案，**未动代码**。

---

## 0. 一句话方案

> 用「**双 Volume 权重切换**」做介质与色调（零渲染风险），用「**水面下表面 Shell**」补上从下方看的水面（这是"看不出在水下"的真正根因），再叠「**浮游颗粒 + 焦散 + 光柱**」把水做成有体积的介质。

---

## 1. 现状盘点（为什么现在看不出在水下）

| # | 事实 | 后果 |
|---|---|---|
| 1 | 第三方水 `M_Water.mat` 的 `_Cull = 2`（**单面、剔除背面**） | 从水下抬头，水面**整个不存在**，直接看到天空 → 完全没有"隔着一层水"的读感 |
| 2 | 没有水下介质：雾是 `28–165m` 的空气透视（近 `#EFF9FA` → 远 `#C8E0E6`），水下沿用同一套 | 水下和水上的能见度、颜色一样 → 没有"浸没"信号 |
| 3 | 没有体积参照物：无浮游颗粒、无焦散、无光柱 | 画面缺尺度，读不出"水"这种介质 |
| 4 | 现有 Global Volume 组件齐全（WhiteBalance / Tonemapping / Bloom / Vignette / SMH / ColorAdjustments / ChromaticAberration / ColorLookup） | **好消息**：色调层可以完全复用，不用新写着色器 |
| 5 | 渲染链路：URP 2022.3（团结）+ FlatKit 三个 Feature（DepthNormals / Outline / Fog），MSAA 4x，HDR，Depth+Opaque 纹理已开 | 具备做全屏后处理和透明读 Opaque 的条件 |
| 6 | `PlayerController.IsSwimming`、`WaterSurface.TrySample` 已存在 | 水下判定不用从零写 |

**结论**：不是"调个色"就能解决，缺的是 **水面下表面** 这一层几何 + 介质梯度。顺序错了会白做（先把颜色调青，抬头还是空的）。

## 2. 视觉目标（吉卜力口径）

### 2.1 三句话

1. **不是蓝色滤镜，是「空气透视」换了一套光**：远处溶进亮青，不是压暗。
2. **光从上面来**：越靠水面越亮越暖，越深越冷越静；抬头必须有一个"发光的窗"。
3. **手绘感靠颗粒和笔触，不靠噪点和色差**：颗粒要少、要慢、要有明暗差。

### 2.2 色卡（沿用风格指南的天空族，不新开色相）

| 用途 | 取色 | 说明 |
|---|---|---|
| 水面窗口（Snell 窗内） | `#BFE3EC` → `#EAF6F2` | 与天空近地色同族，读作「透出去的天空」 |
| 窗口亮斑 / 太阳 | `#FCF7E6`（暖白，**非纯白**） | 全图唯一强亮源 |
| 窗口边缘光环 | `#FFF1DA`，Alpha 0.35 | 吉卜力常见的一圈亮边 |
| 全反射区（水面其余部分） | `#2E86AE` → `#1F5E7A` | 天空顶色的"浸没版"，不是绿 |
| 水中景（10–18m） | `#2E86AE` 混 `#6FB6C9` | 能见度衰减带 |
| 远景雾（18m+） | `#8FCBD8`（**亮**，不是暗） | 空气透视语义：远 = 亮 + 降饱和 |
| 深水暗部 | `#16455C`，明度不低于 18% | 铁律：暗部不死黑 |
| 浮游颗粒 | `#F6F2E2` / `#BFE3EC` 两色交替 | 暖冷交替才有笔触感 |

**禁止**：荧光青、赛博紫、写实深海蓝黑、厚重均匀蓝雾、强色差（>2px）、胶片噪点。

### 2.3 光

| 要素 | 做法 |
|---|---|
| 主光源 | 水面方向（太阳投影），从水下看是**逆光** → 亮斑 + 光柱 |
| 亮度梯度 | 屏幕上部（水面方向）+25%，下部 −20%，按**屏幕空间**做，不依赖深度 |
| 对比 | 比水上再降 6~8（水下更软） |
| 高光 | Bloom 保留，但阈值上调到 1.15，避免整片泛白 |

## 3. 分层方案（按「先解决读感，再补细节」排序）

### L1 · 水下状态与介质（P0，零渲染风险）

**`UnderwaterCameraController`（挂相机）**

- 每帧取 `WaterSurface.TrySample(camera.position)` → `depth = waterY - camera.y`
- 滞回：`depth > 0.15` 入水、`< 0.05` 出水（避免水面附近抖动）
- 输出一个 `0→1` 的 `submerge` 插值（0.35s 平滑），驱动下面所有层
- 供 `PlayerController` / 音效 / UI 查询：`IsUnderwater`

**双 Volume 权重**

- 新建 `Assets/Settings/UnderwaterProfile.asset`，只覆盖需要的组件（不新增自定义组件）：

| 组件 | 水上值（现状） | 水下值 | 目的 |
|---|---|---|---|
| WhiteBalance | Temp +8 / Tint −3 | Temp **−10** / Tint **+5** | 整体转冷转青 |
| ColorAdjustments | Exposure +0.15 / Contrast −6 / Sat +6 | **−0.25 / −12 / −2**，ColorFilter `#8FD3E6` @ 0.18 | 变柔、变"隔着一层水" |
| ShadowsMidtonesHighlights | 影冷高暖 | 影更冷 `(0.92,1.0,1.08)`，高光压到 `(1.02,1.0,0.98)` | 水下没有暖高光 |
| Vignette | 0.16 | **0.30** / 柔度 0.7 / 色 `#123A4A` | 收边 + 压迫感 |
| ChromaticAberration | 0.05 | **0.12** | 极轻，只做"介质"暗示 |
| Bloom | 1.05 / 0.32 | **1.15 / 0.26** | 只让亮斑溢出，不让整片泛白 |

- 用第二个 Global Volume，代码只改 `volume.weight = submerge`（**不做 tween 手写插值，交给 Volume 混合**）

> 这一层单独就能让画面"变了"，但**抬头还是空天**，所以必须接 L2。

### L2 · 水面下表面 Shell（P0，核心）

新建 `Assets/_Project/Shaders/UnderwaterSurface.shader` + `Assets/_Project/Scripts/Water/UnderwaterSurfaceShell.cs`

- **几何**：运行时按 `WaterSurface` 的 `Renderer.bounds` 生成一个水平 Quad（跟随水面高度 −0.03m），仅在 `IsUnderwater` 时启用
- **材质**：`Cull Front`（只画朝下的面）、Transparent、`ZWrite Off`、`Queue = Transparent+10`（在水面之后）
- **算法（Snell 窗）**：
  ```
  θ = 视线与水面法线(向上)的夹角
  θc = asin(1/1.333) ≈ 48.6°   // 水→空气临界角
  window = smoothstep(θc + 3°, θc - 3°, θ)      // 窗内 1 / 窗外 0
  col = lerp(反射色(波纹), 天空色 + 太阳亮斑, window)
  alpha = lerp(0.92, 0.55, window)              // 窗内半透，透出天空
  col += 波纹亮边 * window 边缘                 // 一圈暖白光环
  ```
- **波纹**：世界 XZ 的 3 层 `sin` 叠加（速度 0.3 / 0.6 / 1.1），驱动窗口边缘扭曲与亮度起伏，幅度 ≤ 4% 屏幕
- **太阳亮斑**：按主光方向的屏幕投影做一个椭圆 soft mask，随波纹抖动

**验收**：抬头 → 上方是一个明亮的椭圆"窗口"，边缘有一圈暖白光环，窗口外是青蓝的水面色 —— 一眼就是水底。

> 备选（不改包）：把 `M_Water.mat` 的 `_Cull` 改 0（双面）。**不推荐**：会污染俯视水面，且从下往上看到的仍是"按水面视角调的颜色"，没有 Snell 读感。

### L3 · 深度雾 / 屏幕抖动（P1，需先验深度）

`UnderwaterFogFeature`（ScriptableRendererFeature，`RenderPassEvent = AfterRenderingPostProcessing`）

- 输入：`ScriptableRenderPassInput.Depth`（MSAA 下必须显式声明，否则深度未绑定）
- 三个效果一次 Blit：
  1. **线性深度雾**：`fog = 1 - exp(-max(0, eyeDepth - 6) * density)`，`density ≈ 0.055`；颜色按 `eyeDepth` 从 `#6FB6C9` 渐变到 `#8FCBD8`（远亮近深，反向于常规雾）
  2. **垂直亮度梯度**：`screenUV.y` 自上而下 ×(1.25 → 0.8)
  3. **UV 抖动**：边缘权重更高的正弦扰动，幅度 0.5–1.2px（水感，不是晕浪）
- **风险**：本工程曾有「Scene Depth 恒为 0（reversed-Z 黑图）」的记录 → **第 0 步先跑深度探针**（下方 §6）

### L4 · 浮游颗粒（P1，低成本高收益）

- `UnderwaterMotes.prefab`：粒子跟随相机，发射盒 `10 × 6 × 10`，常驻 80–140 颗
- 尺寸 0.015–0.05m，颜色在 `#F6F2E2` / `#BFE3EC` 间随机，寿命 6–12s，缓慢上浮 + 正弦横摆
- Alpha 随 `submerge` 淡入淡出；只在相机水下时启用
- 参考：风格指南 §1.5「空中有花瓣/孢子漂浮（少量、慢速、有明暗差异）」

### L5 · 焦散（P1，可选）

- 一张程序化 Voronoi 焦散贴图，贴在水底上方 0.02m 的 **additive plane**（按水底地形切分 2–3 块），UV 双层反向滚动
- 强度 0.12–0.2，颜色 `#EAF6F2`
- **不做**地面材质改动（侵入性太大）

### L6 · 光柱（P2）

- 3–4 个锥形 Mesh（加法混合、边缘菲涅尔衰减、UV 滚动噪波），从水面斜向下插入
- 强度随 `submerge` 淡入，缓慢摆动（周期 6–9s）
- 不用屏幕空间 God Rays（与 FlatKit 的 AfterRendering 顺序冲突，收益不值）

### L7 · 收尾（P2）

- 水下 FOV +3、相机跟随阻尼 +20%（水的阻力感）
- 音效：低通 800Hz + 水下 ambience；入水/出水各一个 water splash
- UI：可选的水下边框（不用，交给 Vignette）

## 6. 风险与前置验证

| # | 风险 | 处理 |
|---|---|---|
| R1 | **Scene Depth 恒 0**（历史坑：reversed-Z 黑图） | 第 0 步做探针：临时 Pass 输出 `eyeDepth/20` 灰度 → 若全黑/全白，L3 的深度雾降级为「屏幕梯度雾 + 相机距离近似」，视觉损失可控（吉卜力本来不追求物理雾） |
| R2 | FlatKit Fog 与水下雾叠加变脏 | 水下时把 FlatKit Fog 的 `distance` 收到 8–40m（运行时改 settings 副本），两者同色系 |
| R3 | MSAA 下 Blit 拿不到深度 | Pass 里 `ConfigureInput(ScriptableRenderPassInput.Depth)`；Blit 前后 `cmd.SetRenderTarget` 用 `BuiltinRenderTextureType.CameraTarget` |
| R4 | Shell 与第三方水面 Z-fighting | Shell 下沉 0.03m，`ZWrite Off`、`Queue Transparent`，并只在水下启用 |
| R5 | 相机在水面高度抖动导致状态闪 | 0.15 / 0.05 双阈值 + 0.35s 权重平滑 |
| R6 | 性能（移动端/低端机） | L3 单 Blit、L4 粒子 ≤140、光柱 ≤4 面；提供 `underwaterQuality` 开关（关 L3/L6） |

### 9.2 与设计的偏离（必须知道）

| 项 | 设计 | 实际 | 原因 |
|---|---|---|---|
| L3 实现方式 | `ScriptableRendererFeature` | **相机前置全屏 Quad** | 加 Feature 要手改 FlatKit 的 Renderer Data（已有 3 个 Feature），风险高、没有开关；Quad 在透明队列同样能采样 `_CameraDepthTexture`，且删除即回退 |
| L1 调色 | 独立 `.asset` | **运行时拼 VolumeProfile** | 参数放 Inspector 更好调，且不用手改 YAML；`priority=30` 覆盖场景里的 Global Volume |
| L5 焦散 | additive plane 贴水底 | **暂缓** | 当前 Renderer 没开 Decal Feature，硬贴平面会穿地形；要做需要单独方案（贴地 decal 或地形材质注入） |
| L6 光柱 | P2 | 未做 | 按计划留到 P2 |

### 9.3 新增的玩法改动：下潜键（必要项）

原游泳逻辑里玩家**永远沉不到浮位线以下**（松手只沉到 45% 就停），
第三人称相机挂在角色上方 1.15m，因此**相机永远进不了水面下 → 水下效果永远看不到**。

所以补了最小一组下潜参数（`PlayerController`）：

| 参数 | 默认 | 说明 |
|---|---|---|
| `enableDive` | true | 关掉后回到「只能浮在浮位线」的旧行为 |
| `diveKey` | `LeftControl` | 按住下潜 |
| `diveSpeed` | 2.2 | 下潜速度 |
| `buoyancySpeed` | 1.2 | 松手自动浮回浮位线（鸭子有浮力） |
| `floatLineDeadZone` | 0.06 | 贴线死区，避免浮力/沉降互相打架抖成 10Hz |

竖直逻辑优先级：**空格上浮 > 下潜键 > 浮位线死区 > 浮力/沉降**。

### 9.4 实机验收步骤

1. 入水 → 按 `Ctrl` 下潜，镜头过水面 → 画面在 0.35s 内转青、变柔、暗角加深
2. 抬头 → 上方出现明亮椭圆「Snell 窗」+ 暖白光环，窗外是青蓝水面
3. 平视 → 18m 外溶进亮青雾，近处（<5m）清晰；能看到缓慢漂移的浮游颗粒
4. 松开 Ctrl → 自动浮回 45% 位，镜头出水，效果淡出
5. 站在岸边俯视水面 → 与改动前一致（Shell 只在水下启用）

### 9.5 待观察 / 可能需要调的点

| 现象 | 调哪里 |
|---|---|
| 水下太绿/太蓝 | `UnderwaterCameraController.colorFilter` + `UnderwaterFog._NearColor/_FarColor` |
| 水下太暗 | `postExposure`、`_TopBoost` |
| Snell 窗太大/太小 | `UnderwaterSurface._WindowAngle`（默认 48.6 物理值，风格化可 40~55） |
